# Python Expense Tracker

A beginner Python project to record and calculate personal expenses.

## Current Features
- Add multiple expenses
- Store expense name, amount, and category
- Calculate total spending
- Calculate category-wise spending
- Find the highest expense

## Status
🚧 Work in Progress — more features and functions will be added.

## Concepts Practiced
- Lists and dictionaries
- While loops
- For loops
- Conditional statements
- Basic calculations

Built while learning Python.
